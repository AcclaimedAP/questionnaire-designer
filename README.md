# Questionnaire Designer

## Description

This is a questionnaire designer application.
The use case is to allow a user to create dynamic questionnaires, with live preview and the ability to save and share the questionnaire.

## Install

Clone the repository and run the following command to install the dependencies:

```bash
npm install
```

## Run

Run the following command to start the development server:

```bash
npm run dev
```

## Test

Run the following command to run the tests:

```bash
npm run test
```

## Tech Stack

- Vite
  Used to easily bootstrap the project and provide a modern development experience.
- React
  The assignment had this as a requirement, and it is a solid choice for interactive web applications.
- TypeScript
  I choose to use Typescript to allow for type safety and better development experience through intellisense and type checking.
- Vitest
  Chosen as a natural companion to Vite, providing a robust testing framework with a focus on simplicity and ease of use.
- TailwindCSS
  Easy to quickly style components with a consistent design system and a focus on utility-first approach.
- React Router
  My choice for routing. Simple and easy to use. Alternatives could be Tanstack Router, however I chose React Router due to familiarity.
